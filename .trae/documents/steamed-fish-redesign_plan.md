# 葱油蒸鲈鱼段 - 界面优化计划

## 项目概述

当前项目是一个美食烹饪视频的代码风格字幕模板，用户希望优化界面设计，包括：
1. 为食材添加图片展示（使用动漫风格占位图）
2. 整体网站重新设计，提升视觉效果

## 设计方向

### 视觉风格
- **主题**: 美食烹饪 + 代码风格的融合
- **色调**: 温暖的橙棕色系配合代码风格的深色背景
- **字体**: 保持等宽字体的代码风格，但增加现代感
- **动效**: 流畅的过渡动画和微交互效果

### 核心优化点
1. **食材图片展示**: 为主要食材（鲈鱼、葱、姜、蒸鱼豉油、油）添加动漫风格图片
2. **场景视觉升级**: 每个场景添加独特的视觉元素和背景
3. **动画效果增强**: 添加更丰富的过渡动画和交互反馈
4. **响应式优化**: 确保移动端体验良好

## 文件修改计划

### 1. 新增资源文件
- `steamed-fish/images/` - 存放食材图片资源

### 2. 修改 index.html
- 添加食材图片展示区域
- 优化布局结构
- 添加图片占位容器

### 3. 修改 style.css
- 重新设计整体样式
- 添加食材卡片样式

### 4. 修改 app.js
- 添加图片懒加载逻辑
- 优化场景切换动画

## 详细设计

### 食材图片展示设计
```
┌─────────────────────────────────────┐
│         食材全家福区域              │
├─────────────────────────────────────┤
│   [鲈鱼图片]   [葱图片]   [姜图片]  │
│    鲈鱼 x 1      葱 x 2    姜 x 1  │
├─────────────────────────────────────┤
│   [蒸鱼豉油]   [食用油]             │
│    蒸鱼豉油 x 1   油 x 5g          │
└─────────────────────────────────────┘
```

### 视觉设计要点
- 食材卡片采用圆角设计，带有轻微阴影
- 悬停时显示食材名称和用量
- 支持用户自定义上传真实食材图片
- 若无真实图片，显示动漫风格占位图

2. **Step 2**: 修改 HTML 结构，添加食材展示区域

## 风险评估

| 风险 | 描述 | 应对策略 |
|------|------|----------|
| 图片加载慢 | 动漫风格图片可能较大 | 使用压缩图片格式，实现懒加载 |
| 布局兼容问题 | 不同屏幕尺寸适配 | 使用响应式设计，测试多设备 |
| 用户上传图片 | 需要预留位置 | 添加自定义图片上传接口预留 |

## 预期效果

完成后，网站将具有以下特点：
- 更加美观的视觉设计
- 清晰的食材图片展示
- 流畅的动画效果
- 良好的移动端适配
- 用户可自定义食材图片的预留位置
