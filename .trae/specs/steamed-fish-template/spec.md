# 葱油蒸鲈鱼段 - 视频字幕模板

## Overview
- **Summary**: 这是一个用于美食烹饪视频的网页字幕模板，实现了代码风格的交互界面，包含开场定帧、食材参数、预处理、蒸煮进度、核心操作和结尾等多个部分，每个部分都有独特的动画效果。
- **Purpose**: 将用户的视频字幕需求转化为一个可交互、视觉效果精美的网页模板，模拟视频中的字幕展示过程。
- **Target Users**: 美食视频创作者、需要代码风格字幕的视频制作者。

## Goals
- 实现完整的字幕流程，包含所有用户指定的文本内容
- 实现打字机、进度条等多种动画效果
- 响应式设计，适配各种屏幕尺寸
- 使用纯 HTML + CSS + JS 实现，无需依赖外部库
- 提供交互按钮，让用户可以手动控制字幕切换

## Non-Goals (Out of Scope)
- 不实现真实的视频播放功能
- 不添加后端服务
- 不添加视频录制功能
- 不添加用户认证系统

## Background & Context
- 用户需要一个代码风格的视频字幕模板，用于制作美食烹饪视频
- 所有内容需要使用等宽字体，配合打字机动画效果
- 需要按照指定的顺序和时机展示不同内容

## Functional Requirements
- **FR-1**: 展示开场定帧字幕（3秒停留）
- **FR-2**: 实现打字机效果展示食材参数
- **FR-3**: 插入食材全家福图片（2秒停留）
- **FR-4**: 展示预处理步骤
- **FR-5**: 展示蒸煮进度条动画
- **FR-6**: 展示核心操作（淋油）界面
- **FR-7**: 可选展示「滋啦——」大字效果
- **FR-8**: 展示营养成分 return 值
- **FR-9**: 展示结尾定帧字幕（4秒停留）
- **FR-10**: 提供按钮让用户可以手动切换各场景

## Non-Functional Requirements
- **NFR-1**: 使用等宽字体，保持代码风格
- **NFR-2**: 动画流畅，帧率稳定在 60fps
- **NFR-3**: 响应式设计，支持移动设备和桌面设备
- **NFR-4**: 代码结构清晰，易于维护

## Constraints
- **Technical**: 纯 HTML + CSS + JS，不使用外部库或框架
- **Business**: 无预算限制
- **Dependencies**: 无外部系统依赖

## Assumptions
- 用户会使用现代浏览器（支持 CSS3 和 ES6+）
- 食材全家福图片可以使用占位图

## Acceptance Criteria

### AC-1: 开场定帧展示
- **Given**: 用户打开网页
- **When**: 页面加载完成
- **Then**: 显示开场定帧，黑底白字，等宽字体，内容为「/* 葱油蒸鲈鱼段.c */ // 练后高蛋白补给 | 总耗时: 16min | 蛋白质: ~33g」
- **Verification**: `programmatic`

### AC-2: 食材参数打字机效果
- **Given**: 用户点击进入第一幕或自动播放到第一幕
- **When**: 场景切换到第一幕
- **Then**: 食材参数以打字机动画逐行显示，每行间隔1秒
- **Verification**: `programmatic`

### AC-3: 预处理展示
- **Given**: 用户点击进入第二幕或自动播放到第二幕
- **When**: 场景切换到第二幕
- **Then**: 显示预处理步骤，带黑色半透明背景框
- **Verification**: `programmatic`

### AC-4: 蒸煮进度展示
- **Given**: 用户点击进入第三幕或自动播放到第三幕
- **When**: 场景切换到第三幕
- **Then**: 逐行显示蒸煮进度，每行有进度条和说明文字
- **Verification**: `programmatic`

### AC-5: 淋油操作展示
- **Given**: 用户点击进入第四幕或自动播放到第四幕
- **When**: 场景切换到第四幕
- **Then**: 显示带边框的代码框样式界面
- **Verification**: `programmatic`

### AC-6: 滋啦效果展示
- **Given**: 用户在第四幕点击「滋啦效果」按钮
- **When**: 触发后
- **Then**: 显示全屏大字「滋啦——」1秒
- **Verification**: `programmatic`

### AC-7: 营养成分展示
- **Given**: 用户点击进入第五幕或自动播放到第五幕
- **When**: 场景切换到第五幕
- **Then**: 显示营养成分的 return 值，打字机效果
- **Verification**: `programmatic`

### AC-8: 结尾定帧展示
- **Given**: 用户点击进入结尾或自动播放到结尾
- **When**: 场景切换到结尾
- **Then**: 显示结尾定帧，黑底白字，等宽字体
- **Verification**: `programmatic`

### AC-9: 手动交互功能
- **Given**: 网页已加载
- **When**: 用户点击「下一步」或「上一步」按钮
- **Then**: 场景相应切换
- **Verification**: `programmatic`

### AC-10: 视觉风格一致
- **Given**: 任意场景
- **When**: 展示字幕时
- **Then**: 整体视觉风格一致，均为代码风格，等宽字体
- **Verification**: `human-judgment`
